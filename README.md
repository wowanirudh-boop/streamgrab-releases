# StreamGrab desktop app

The Windows desktop app that downloads the videos the **StreamGrab** Chrome
extension detects. The extension does not work without it.

## Download

**[⬇ Download StreamGrab for Windows](https://github.com/wowanirudh-boop/streamgrab-releases/releases/latest/download/StreamGrab-Setup.exe)**

All versions are on the [Releases](https://github.com/wowanirudh-boop/streamgrab-releases/releases) page.

Or install from a terminal with [winget](https://learn.microsoft.com/windows/package-manager/):

```
winget install AnirudhSangubhotla.StreamGrab
```

## Install

1. Run the installer.
2. Open StreamGrab once. It stays in the system tray and registers itself with Chrome.
3. Install the StreamGrab extension from the Chrome Web Store, play a video, and click Download.

## Windows SmartScreen

The installer is not code-signed yet, so Windows may show "Windows protected your PC" on first run.
Click **More info**, then **Run anyway**.

## Requirements

Windows 10 or 11, 64-bit. Google Chrome, Edge, Brave or Vivaldi.

## Limitations

DRM-protected services (Netflix, Disney+, Prime Video and similar) are not supported.
Downloading is for content you own or that permits it.
